# MEHFIL — A Late-Night Ghazal Listening Room

> *"A quiet night in an old city. Somewhere inside, a ghazal is playing and everyone has gone silent."*

**MEHFIL** (महफ़िल) is an atmospheric, late night web app designed for Ghazal lovers. It pairs timeless masterpieces from legendary maestroes with aesthetic room visuals, classical Devanagari typography, warm candlelit lighting, and mobile background playback.

---

## Features

-  **Atmospheric Room Environments**: Switch between **Classic Room**, **Warm Room**, and **Haveli Room**.
- **Warm Lamp Glow Mode**: Interactive candlelit lighting (`G` key or toggle button) that casts a golden glow over the room.
- **Handpicked Ghazal Collection**: Curated collection featuring Jagjit Singh, Mehdi Hassan, Ghulam Ali, Pankaj Udhas, Piyush Mishra, Nusrat Fateh Ali Khan, Sajjad Ali, Kishore Kumar, and Javed Bashir.
- **Mobile Lock Screen & Background Playback**: Integrated Web Media Session API and HTML5 audio keep-alive engine for lock screen controls & mobile background playback.
- **Smart Session Resume**: Automatically remembers your exact track and timestamp across visits.
- **Shuffle & Quick Artist Filters**: Filter by favorite artists or listen in random shuffle order.

---

## Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/router) (React + Vite)
- **Styling**: Tailwind CSS v4 + Custom Glassmorphism & Animations
- **Icons**: [Lucide React](https://lucide.dev)
- **Audio Engine**: YouTube IFrame API + Web Media Session API + HTML5 Audio

---

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
